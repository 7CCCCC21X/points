1添加地址 / 采集累计总榜地址

一键流程：按总榜顺序采集到目标地址数（默认前 10000 名）或游标到底，随后自动逐个查询每周积分， 全部缓存在本机。中途停止或刷新后再点一次即可从断点继续。

总榜功能按前版接口适配，权限与分页参数待实测；接口不可用时可导入地址。重置游标不会删除已查询的积分。

2查询历史周积分

正在读取本机缓存…

接口一次返回地址的全部周，每次查询都按周合并保存：已结算的历史周永久留在本机缓存，随时可看。 勾选“同时查询官网 PNL”时每个地址多一次请求，取官网 Portfolio 的累计 PNL 时序，按周期锚点在各周起止时刻取累计值相减得到周 PNL；本机只保存各周界的累计值（需在 Vercel 配置 PREDICT_GRAPHQL_AUTH / COOKIE）。 勾选“同时查询资金总量”时每个地址再多一次请求：取官网 Portfolio 的持仓金额，并读取钱包在 BNB 链上的 USDT 余额，两者相加为资金总量（持仓部分同样需要 PREDICT_GRAPHQL_AUTH / COOKIE）。 勾选“只查总榜前 N 名”时，三个查询按钮和一键流程都只处理总榜名次 ≤ 采集目标数的地址， 手动导入、没有名次的地址不会被查。“查询 / 继续未完成地址”查未成功的地址，以及旧缓存缺少手续费、交易量等新字段或还没查过 PNL / 资金总量的地址；“更新到最新周”在此基础上再查还没包含最新结算周、PNL 还没覆盖最新结算周或资金总量出错的地址，其余跳过。这些勾选和数字设置会记在本浏览器里，刷新后保持。 整体速率 = 1 / 请求间隔，并发只影响同时在途的请求数；上游限流时会自动退避。

3排行榜：选择榜单与周、查看排名、下载 CSV

名次是当前样本内的排名，不是官方全网榜；同分并列。表格里的积分与金额四舍五入到整数显示，悬停可见完整数值，CSV 导出保留全部小数（积分成本保留小数）。周排名只给查询成功、明确已结算且积分有效的记录； 合计榜按每个地址所有已结算周的周积分相加。PNL 榜可切换升序（亏损最多在前）或降序（盈利最多在前）。 手续费口径与 yuce 一致：周手续费 = 接口返回的该周 paid_fee_usdt × 手续费折扣（默认 0.9，填 1 为接口原值），未结算的本周也有值； 全部手续费 = 该地址所有周的周手续费相加；积分成本 = 周手续费 ÷ 周积分，只对已结算且积分有效的周计算，越低越好。 周交易量 = 接口返回的该周 paid_volume_usdt + free_volume_usdt（付费 + 免费，同 yuce 的“总交易量”），不乘折扣，付费与免费分列显示。 资金总量 = 官网持仓金额 + 钱包 USDT 余额（同 yuce 的“净资产”），是查询时刻的值，不按周；悬停可见拆分。点击名称可查看该地址各周积分与排名；钱包地址只显示首尾，悬停查看完整地址，点击跳转到 predict.fun 的 portfolio 页面。
